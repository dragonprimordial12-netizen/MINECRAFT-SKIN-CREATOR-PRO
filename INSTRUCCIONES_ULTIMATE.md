### ⚙️ TAB 2: AVANZADO (Herramientas Profesionales)

#### Modelo de Personaje
- **👤 Steve** - Modelo clásico (brazos anchos)
- **👧 Alex** - Modelo delgado (brazos estrechos)

#### Generador Aleatorio
- Botón **🎲 Generar skin aleatoria**
- Crea colores y nombre al azar
- Perfecto para inspiración o sorpresas

#### Historial de Cambios
- **↶ Deshacer** - Vuelve a tu color anterior
- **↷ Rehacer** - Restaura el color desecho
- Muestra: **X / Total** cambios realizados
- ¡Hasta 50 cambios en el historial!

#### Copiar Código de Colores
- **Caja de texto** con código JSON
- Copia y pega para compartir con amigos
- Formato: `{ "head": "#2d2d5c", "body": "..." }`

---

### 🖼️ TAB 3: GALERÍA LOCAL

#### Guardar Skins Localmente
- **💾 Guardar local** - Guarda tu skin actual en el navegador
- La skin se **guarda automáticamente** en localStorage
- **No requiere internet** una vez guardada

#### Administrar Skins Guardadas
- **Muestra todas tus skins** con nombre y fecha
- **⬆️ Cargar** - Restaura esa skin como la actual
- **🗑️ Eliminar** - Borra la skin guardada
- Puedes guardar **ilimitadas skins**

#### Nota Importante
- Las skins se guardan en tu navegador actual
- Si limpias el caché, se borran
- **Descarga las skins importantes en PNG**

---

## 💾 EXPORTAR E IMPORTAR

### Exportar Preset (📤 Exportar preset)
- Guarda tu skin como archivo `.json`
- Incluye nombre y todos los colores
- **Compartir con amigos**
- Archivo pequeño y portable

### Importar Preset (📂 Importar preset)
- Carga un archivo `.json` previo
- Restaura una skin exportada
- **Trabajar en múltiples dispositivos**

### Ejemplo de Preset JSON
```json
{
  "name": "Dragón Épico",
  "colors": {
    "head": "#2d2d5c",
    "body": "#3d4a6b",
    "limbs": "#5a4a8a",
    "accent": "#ff6b9d",
    "eyes": "#ffff00"
  }
}
```

## 📥 DESCARGAR TU SKIN

### Botón: 📥 Descargar PNG
1. Haz clic en "Descargar PNG"
2. Se abre tu carpeta de Descargas
3. Archivo: `[NombreSkin]_skin.png`
4. ¡Listo para subir a TLauncher!

### Pasos para Subir en TLauncher
1. Abre **TLauncher**
2. Ve a **"Área de usuario"**
3. Haz clic en **"Subir skin"**
4. Selecciona tu PNG descargado
5. Elige **Classic** o **Slim**
6. Haz clic en **"Aceptar"**
7. ¡Tu skin está en el juego! 🎮

## 🛠️ PREGUNTAS FRECUENTES

### ¿Dónde se guardan mis skins?
- En el **localStorage** de tu navegador
- Datos locales, no en servidores
- Accesibles solo en este navegador

### ¿Puedo usar la misma skin en múltiples dispositivos?
- Sí, exporta como `.json`
- Luego importa en otro dispositivo
- O descarga el PNG y súbelo a TLauncher

### ¿Qué pasa si limpio el caché del navegador?
- Se pierden las skins guardadas localmente
- Pero tienes tus PNGs descargados
- Siempre exporta presets importantes

### ¿Funciona en móvil?
- Sí, totalmente responsive
- Pantalla táctil compatible
- Funciona en Chrome, Firefox y Safari

### ¿Las skins son 64x64 píxeles?
- Sí, estándar oficial de Minecraft
- Compatible con Java Edition
- Funciona en todos los clientes

### ¿Puedo compartir mis skins con amigos?
- Descarga PNG y comparte directamente
- O exporta preset JSON
- Ambas opciones son portables
